📐 CADデータ取得・SP登録アシスタント

型番からメーカーサイトのCAD(DWG優先、無ければDXF)を取得し、部品CAD フォルダに 型番.dwg で保存します。依頼内容はスプレッドシート(CADデータ管理表)に記録されます。対応メーカー: オムロン / キーエンス / ミスミ

CAD取得を依頼する CADデータ管理表を開く

1. 初回準備(PCごとに1回)

  1. Node.js(LTS)と Google Chrome をインストールします。
  2. コマンドプロンプトで次を実行します。
mkdir %LOCALAPPDATA%\cad-tool
cd %LOCALAPPDATA%\cad-tool
npm init -y
npm install playwright adm-zip
依存パッケージは Google ドライブ上に置かないでください(ファイルが壊れます)。

2. メーカーサイトにログイン(最初の1回)

ツールのフォルダへ移動して実行します。Chromeが開くので会員アカウントでログインし、ターミナルで Enter を押します。

cad.cmd login omron
cad.cmd login keyence
cad.cmd login misumi
  • オムロン: I-Webメンバーズ登録が必要です。
  • キーエンス: Web会員登録が必要です。CAD使用許諾への同意はツールが自動で進めます。
  • ミスミ: 会員登録が必要です。初回のみ、ログイン後にブラウザで対象CADを手動で1件ダウンロードし、規約同意と形式選択を済ませてください。

3. CADを取得する

cad.cmd get MY2-02-AC110/120
cad.cmd get HFS5-2020-1000 --mfr misumi
cad.cmd status
  • 保存済みの型番は取得せずに知らせます。取り直す場合は --force を付けます。
  • メーカーの自動判定に失敗したら --mfr で指定します。

注意事項

  • Chromeの画面が開きます。実行中はウィンドウを操作しないでください。
  • キーエンスは2D CADがDXFのみです(自動でDXF取得)。
  • ミスミの寸法未確定の受注生産品は、確定した型番で指定してください。
  • 型番と図面形式は1対1とは限りません。選ばれた形式名が画面に表示されるので確認してください。
